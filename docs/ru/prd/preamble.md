## Порядок применения требований

Для каждого требования, контракта данных, перечисления, правила и версии определён один ответственный раздел. Ссылки из других разделов не создают второго контракта. При расхождении применяется положение ответственного раздела, указанного в приложении A.

Русская и английская редакции описывают одни требования. Идентификаторы, формулы и критерии приёмки совпадают; редакционные изменения вносятся в обе версии одновременно.
