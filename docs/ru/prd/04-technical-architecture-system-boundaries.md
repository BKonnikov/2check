## 4.1. Технологии MVP

- Клиентская часть: Next.js.
- Серверная часть: Node.js/Fastify **или** Python/FastAPI.
- Redis: обязателен.
- Размещение MVP: один VPS.

Язык и среда выполнения серверной части определяются технической архитектурой и не меняют продуктовый контракт.

## 4.2. Компоненты выполнения

Основные логические компоненты:

```text
Web Frontend
Internal Web API
Scan Orchestrator
DNS Module
Registry Module
TLS Module
Security Validation
Redis Reusable Cache
Scan Store
Sensitive/Gated Store
Observability
```

## 4.3. Граница сетевого доступа

Указанная пользователем цель не передаётся произвольному сетевому клиенту напрямую. Сетевой запрос проходит этапы CanonicalDomain → необходимые DNS-проверки → проверка безопасности → соединение с закреплённым IP-адресом.

## 4.4. HTTPS самой платформы

Веб-интерфейс и API 2check используют доверенный HTTPS-сертификат. Управление собственным сертификатом является эксплуатационной зависимостью платформы.

## 4.5. Критерии приёмки

- **AC-4.1** Redis является обязательным компонентом MVP.
- **AC-4.2** MVP может быть развёрнут на одном VPS.
- **AC-4.3** Корректность MVP не зависит от Kubernetes, нескольких регионов или распределённого планировщика.
- **AC-4.4** Сетевые модули не обходят проверку безопасности.
- **AC-4.5** Публичные веб-интерфейс и API 2check обслуживаются через доверенный HTTPS.
