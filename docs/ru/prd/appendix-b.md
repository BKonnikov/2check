# Приложение B. Условия согласованности

<!-- nav:start -->
[Концепция](../01-concept.md) · [Оглавление PRD](../02-prd.md) · [English](../../en/prd/appendix-b.md)
<!-- nav:end -->

Спецификация считается согласованной при выполнении следующих условий:

- каждому смысловому объекту соответствует один DTO;
- для каждого измерения конфигурации используется одно каноническое имя поля версии;
- устаревшие коды причин отсутствуют;
- правила именования метрик не дублируются;
- клиент не выводит серверные правила оценки и повторной попытки самостоятельно;
- представления Public/Technical не содержат защищённых персональных данных или секретов;
- модель доступа по `scanId` определена явно;
- правила FULL/PARTIAL определены явно;
- приём через `POST /scans` отделён от получения конечного результата через `GET`;
- числовая оценка и уверенность остаются независимыми показателями;
- кэш повторного использования и исторический ScanResult имеют разное назначение;
- сбои проверки безопасности и сетевого выполнения различимы;
- отправка изображения не создаёт хранилища или сущности ссылки общего доступа;
- критерии приёмки пронумерованы последовательно внутри каждого раздела;
- временные пометки исправлений, продолжений и критериев-заглушек отсутствуют.
