# 12. Числовая оценка здоровья домена

<!-- nav:start -->
[Концепция](../01-concept.md) · [Оглавление PRD](../02-prd.md) · [English](../../en/prd/12-domain-health-score.md)
<!-- nav:end -->

§12 определяет правила расчёта числовой оценки.

## 12.1. Применимость

Оценка существует только для `FULL + FINAL`.

## 12.2. Формула

```text
score = max(0, 100 - sum(issuePenalty))
```

Оценка рассчитывается по проблемам Issue с устранёнными повторами, а не по исходным проверкам FAIL.

## 12.3. Рекомендуемые штрафы по умолчанию

```text
critical      -25
warning        -8
informational  -2
```

Значения задаются конфигурацией.

## 12.4. Состояния без штрафа

PASS, UNKNOWN, NOT_APPLICABLE → штраф 0.

Сниженная уверенность не уменьшает числовую оценку.

## 12.5. Детализация оценки — ScoreBreakdown

```text
ScoreBreakdown {
  baseScore
  penalties[]
  totalPenalty
  finalScore
}

ScorePenalty {
  issueId
  severity
  points
}
```

## 12.6. Версионирование

Исторический ScanResult сохраняет исходные `healthPolicyVersion` и оценку. Новая политика не пересчитывает старое сканирование.

## 12.7. Критерии приёмки

- **AC-12.1** Оценка доступна только для FULL FINAL.
- **AC-12.2** Оценка рассчитывается по Issue.
- **AC-12.3** UNKNOWN/N/A не получают штрафа.
- **AC-12.4** Нижняя граница оценки равна 0.
- **AC-12.5** Сниженная уверенность не меняет числовую оценку.
- **AC-12.6** Историческая оценка неизменяема.
