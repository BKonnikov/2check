## 2.1. MVP 1.0

В MVP 1.0 входят:

- предварительная обработка ввода и преобразование IDN;
- канонический объект домена CanonicalDomain;
- сравнение ответов DNS-резолверов;
- проверка регистрации домена через `registryProvider`;
- фиксированный набор проверок SSL/TLS;
- сводка технического здоровья домена;
- модель статусов, серьёзности и зависимостей проверок;
- объединение выявленных проблем;
- числовая оценка здоровья домена и показатель уверенности;
- кэш Redis;
- защита от SSRF;
- веб-интерфейс и внутренний веб-API;
- RU / UZ / EN.

## 2.2. MVP 1.1

**Проверка состояния почты**:

- SPF;
- DMARC;
- DKIM;
- MX;
- STARTTLS;
- PTR;
- проверка принимающего почтового сервера по чёрным спискам.

Проверки состояния почты не входят в MVP 1.0, в том числе частично.

## 2.3. Фаза 2

- географически распределённая проверка DNS;
- Ping / Traceroute;
- HTTP-заголовки и цепочки перенаправлений;
- репутация домена;
- выявление омографов и подмены IDN;
- подробные руководства по устранению проблем с учётом SEO.

## 2.4. Фаза 3

- Telegram-бот;
- публичный API;
- комплексное сканирование с использованием SSE;
- сканирование портов;
- мониторинг доступности.

## 2.5. Критерии приёмки

- **AC-2.1** Проверки состояния почты отсутствуют в MVP 1.0.
- **AC-2.2** Проверки HTTP и репутации, сканирование портов и мониторинг доступности отсутствуют в MVP 1.0.
- **AC-2.3** Сравнение резолверов в MVP не представляется как географически распределённая проверка DNS.
- **AC-2.4** Новая проверка не включается в MVP без явного изменения его границ.
