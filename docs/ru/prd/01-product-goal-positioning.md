## 1.1. Позиционирование

**2check.uz — проверка технического здоровья домена простым языком.**

Продукт предназначен для двух аудиторий:

- **обычный пользователь / владелец бизнеса** — получает понятный вердикт, объяснение проблемы и краткую рекомендацию;
- **технический пользователь** — получает нормализованные данные и безопасное представление технических подробностей.

Главный результат — **вердикт о техническом здоровье домена**. Числовая оценка служит дополнительным ориентиром.

## 1.2. Принципы продукта

1. Правила оценки технического здоровья домена определяются серверной частью.
2. Один корневой дефект не должен приводить к нескольким независимым штрафам.
3. Техническая неопределённость не должна трактоваться как проблема домена.
4. Блокировка при невозможности подтвердить безопасность имеет приоритет над пропускной способностью и удобством интерфейса.
5. Границы MVP не расширяются за счёт дополнительных проверок, даже если их реализация кажется простой.
6. Русский, узбекский и английский языки (RU / UZ / EN) обязательны начиная с MVP.

## 1.3. Критерии приёмки

- **AC-1.1** Основной результат содержит понятный вердикт; числовая оценка занимает второстепенное место.
- **AC-1.2** Клиентская часть не рассчитывает показатели технического здоровья домена самостоятельно.
- **AC-1.3** Техническому пользователю доступно безопасное представление данных, а не внутренний DTO или необработанная выгрузка.
- **AC-1.4** RU / UZ / EN поддерживаются начиная с MVP.
