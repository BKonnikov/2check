# 3. Пользовательские сценарии и режимы сканирования

## 3.1. Основной сценарий

Основное действие запускает сканирование со следующими параметрами:

```text
mode = FULL
cacheMode = NORMAL
```

Режим FULL включает:

```text
DNS + Registry + TLS
```

## 3.2. Частичное сканирование — PARTIAL

Технический пользователь может выбрать непустое подмножество категорий:

```text
dns | registry | tls
```

Если выбраны все три категории, используется `FULL`, а не `PARTIAL`.

## 3.3. Страницы инструментов

```text
/dns-check → PARTIAL [dns]
/whois     → PARTIAL [registry]
/ssl-check → PARTIAL [tls]
```

Страницы инструментов используют те же серверные модули и правила обработки, что и полное сканирование FULL.

## 3.4. Общая сводка

Общая числовая оценка и общий вердикт доступны только для `FULL + FINAL`.

PARTIAL показывает результаты выбранных категорий без общей оценки здоровья домена.

## 3.5. Критерии приёмки

- **AC-3.1** Основной сценарий создаёт сканирование FULL с режимом кэша NORMAL.
- **AC-3.2** PARTIAL допускает только непустое подмножество категорий FULL.
- **AC-3.3** Выбор DNS, регистрации домена и TLS создаёт сканирование FULL.
- **AC-3.4** Страницы инструментов не вводят собственные правила технической обработки.
- **AC-3.5** PARTIAL не получает общей числовой оценки или общего вердикта.
