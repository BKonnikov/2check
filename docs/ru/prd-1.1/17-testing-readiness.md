# 17. Тестирование и готовность к выпуску

<!-- nav:start -->
[Концепция](../01-concept.md) · [Оглавление PRD 1.1](../03-prd-1.1.md) · [English](../../en/prd-1.1/17-testing-readiness.md)
<!-- nav:end -->

§17 определяет, чем подтверждается выполнение требований этого документа и при каких условиях категория выпускается. Ответственный раздел для стратегии тестирования — 1.0 §26.

## 17.1. Что проверяется без сети

Разбор записей, счёт ограничений и выбор статуса — чистые функции над заранее записанными ответами. Они покрываются тестами без обращения к сети, и это покрытие обязательно.

Обязательные наборы данных:

| Набор | Что в нём |
|---|---|
| записи SPF | превышение предела терминов, цикл, все виды `all`, пустые запросы |
| записи DMARC | обход дерева, непризнанная запись, несколько записей, `pct` |
| ключи DKIM | пустой ключ, короткий ключ, режим испытания, `ed25519` |
| записи `MX` | заявленный отказ от почты, неявный узел, псевдоним, адрес вместо имени |

Набор записей DMARC — самый важный из четырёх. Обход дерева — единственное место, где проверка сама решает, к какому домену относится найденное, и ошибка там приводит не к неверному статусу, а к верному статусу о чужом домене.

## 17.2. Что проверяется с сетью

Проба шифрования требует соединения и потому проверяется отдельно, вне обязательного набора сборки. Обязательным остаётся то, что от сети не зависит: фиксированный порт, отсутствие команд передачи данных, источник имён узлов, поведение при запрете доступа.

## 17.3. Условия выпуска

Категория выпускается при выполнении всех условий:

- покрыты тесты §16.1;
- перечень недопустимых причинных связей §11.2 проверяется автоматически;
- узбекские формулировки присутствуют для каждого сообщения — §11;
- исходящие соединения на почтовый порт доступны в целевом развёртывании, либо категория выпускается с честным `UNKNOWN` для проверки шифрования — §7.

Последнее условие сформулировано с развилкой намеренно. Недоступность порта — не причина откладывать шесть остальных проверок, если седьмая честно сообщает, что её выполнить нельзя.

## 17.4. Что проверяется вручную

| Что | Почему нельзя автоматически |
|---|---|
| понятность сообщений для читателя без опыта | требует читателя |
| поведение страницы инструмента на телефоне | требует устройства — 1.0 §26 |

## 17.5. Критерии приёмки

- **AC-17.1** Разбор записей и выбор статуса покрыты тестами без обращения к сети.
- **AC-17.2** Набор данных DMARC содержит запись у вышестоящего домена, и тест подтверждает, что источник политики сообщается верно.
- **AC-17.3** Ограничения пробы шифрования, не зависящие от сети, покрыты обязательными тестами.
- **AC-17.4** Перечень недопустимых причинных связей проверяется автоматически.
- **AC-17.5** Выпуск с недоступным почтовым портом допускается при честном `UNKNOWN` для проверки шифрования.
