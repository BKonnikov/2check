# 18. Тестирование и готовность к выпуску

<!-- nav:start -->
[Концепция](../01-concept.md) · [Оглавление PRD 1.1](../03-prd-1.1.md) · [English](../../en/prd-1.1/18-testing-readiness.md)
<!-- nav:end -->

§18 определяет, чем подтверждается выполнение требований этого документа и при каких условиях категория выпускается. Ответственный раздел для стратегии тестирования — 1.0 §26.

## 18.1. Что проверяется без сети

Разбор записей, счёт ограничений и выбор статуса — чистые функции над заранее записанными ответами. Они покрываются тестами без обращения к сети, и это покрытие обязательно.

Обязательные наборы данных:

| Набор | Что в нём |
|---|---|
| записи SPF | превышение предела терминов, цикл, все виды `all`, пустые запросы |
| записи DMARC | обход дерева, непризнанная запись, несколько записей, `pct` |
| ключи DKIM | пустой ключ, короткий ключ, режим испытания, `ed25519` |
| записи `MX` | заявленный отказ от почты, неявный узел, псевдоним, адрес вместо имени |
| ответы списков | попадание, отсутствие, отказ обслуживать запрос |

Набор ответов списков — самый важный из пяти. Ответ-отказ по форме неотличим от попадания, и тест, где он есть, — единственное, что не даёт ошибке §9 вернуться незамеченной.

## 18.2. Что проверяется с сетью

Проба шифрования требует соединения и потому проверяется отдельно, вне обязательного набора сборки. Обязательным остаётся то, что от сети не зависит: фиксированный порт, отсутствие команд передачи данных, источник имён узлов, поведение при запрете доступа.

## 18.3. Условия выпуска

Категория выпускается при выполнении всех условий:

- покрыты тесты §18.1;
- перечень недопустимых причинных связей §12.2 проверяется автоматически;
- узбекские формулировки прочитаны носителем языка — §12;
- набор списков блокировок содержит только разрешающие использование, со ссылкой на условия для каждого — §9;
- исходящие соединения на почтовый порт доступны в целевом развёртывании, либо категория выпускается с честным `UNKNOWN` для проверки шифрования — §7.

Последнее условие сформулировано с развилкой намеренно. Недоступность порта — не причина откладывать шесть остальных проверок, если седьмая честно сообщает, что её выполнить нельзя.

## 18.4. Что проверяется вручную

| Что | Почему нельзя автоматически |
|---|---|
| понятность сообщений для читателя без опыта | требует читателя |
| узбекские формулировки | требует носителя языка |
| поведение страницы инструмента на телефоне | требует устройства — 1.0 §26 |

## 18.5. Критерии приёмки

- **AC-18.1** Разбор записей и выбор статуса покрыты тестами без обращения к сети.
- **AC-18.2** Набор данных ответов списков содержит ответ-отказ, и тест подтверждает, что он не читается как отсутствие попадания.
- **AC-18.3** Ограничения пробы шифрования, не зависящие от сети, покрыты обязательными тестами.
- **AC-18.4** Перечень недопустимых причинных связей проверяется автоматически.
- **AC-18.5** Выпуск без прочтённых носителем узбекских формулировок не допускается.
- **AC-18.6** Выпуск с недоступным почтовым портом допускается при честном `UNKNOWN` для проверки шифрования.
