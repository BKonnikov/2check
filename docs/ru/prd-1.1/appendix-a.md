# Приложение A. Ответственные разделы

<!-- nav:start -->
[Концепция](../01-concept.md) · [Оглавление PRD 1.1](../03-prd-1.1.md) · [English](../../en/prd-1.1/appendix-a.md)

Для каждого требования определён один ответственный раздел. При расхождении между разделами применяется положение ответственного.

| Предмет | Ответственный раздел |
|---|---|
| Границы релиза | §1 |
| Группы проверок и зависимость от `MX` | §2 |
| Разбор SPF и его ограничения | §3 |
| Политика DMARC и обход дерева | §4 |
| Поиск ключа DKIM и селекторы | §5 |
| Принимающий сервер | §6 |
| Проба шифрования | §7 |
| Обратные имена | §8 |
| Контракты данных и уровни раскрытия | §9 |
| Объединение проблем и влияние на оценку | §10 |
| Формулировки и запреты на причинные связи | §11 |
| Ключи кэша и сроки жизни | §12 |
| Правила исходящих соединений | §13 |
| Контракт веб-API и объём проверки | §14 |
| Интерфейс и страница инструмента | §15 |
| Метрики и границы аналитики | §16 |
| Условия выпуска | §17 |

Требования, ответственный раздел которых находится в MVP 1.0, этим документом не переопределяются.
