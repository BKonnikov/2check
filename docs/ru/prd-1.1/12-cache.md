§12 определяет ключи кэша категории `email`, сроки жизни записей и то, что кэшировать нельзя. Ответственный раздел — 1.0 §14; режимы кэша, объединение одновременных запросов и правила устаревания здесь не меняются.

## 12.1. Ключи

Ключ строится отдельно для политик и для узлов.

```text
asciiHostname
policy
selector?
resolverSetVersion
emailModuleConfigVersion
cacheContractVersion
```

```text
mailHost
ipFamily?
emailModuleConfigVersion
cacheContractVersion
```

`selector` входит в ключ политик и обязателен для DKIM. Без него ответ по одному селектору переиспользовался бы для другого, и читатель получил бы чужой ключ как свой.

Язык в ключ не входит — 1.0 §14.

## 12.2. Сроки жизни

| Что кэшируется | Порядок срока |
|---|---|
| политики SPF, DMARC, DKIM | часы |
| записи `MX` и адреса узлов | часы |
| результат пробы шифрования | часы |

Точные значения задаются версионируемой конфигурацией по правилам 1.0 §20.

Срок для пробы шифрования — верхняя граница диапазона: это единственная проверка категории, требующая соединения, а настройка шифрования на почтовом узле меняется редко.

Срок для политик, наоборот, ближе к нижней. Политику правят именно тогда, когда её проверяют, и читатель, исправивший запись и нажавший «проверить заново», должен увидеть исправленное.

## 12.3. Чего кэшировать нельзя

| Что | Почему |
|---|---|
| неполный обход дерева DMARC | результат не получен, а не получен отрицательный результат |
| незавершённая проба шифрования | то же |
| селектор, введённый читателем | принадлежит запросу, а не домену |

Последняя строка существенна: введённый селектор не делает результат достоянием домена. Другой читатель, не назвавший селектора, должен получить `UNKNOWN`, а не готовый ответ, найденный по чужой подсказке.

Правила кэширования технических неудач в остальном — 1.0 §14.

## 12.4. Свежесть

`checkedAt` содержит время наблюдения, а не обращения к кэшу — 1.0 §6.

Для проверки, опрашивающей несколько узлов, — §7 — временем наблюдения считается самое раннее из времён, вошедших в результат. Результат не свежее самой старой его части.

## 12.5. Критерии приёмки

- **AC-12.1** Ключ политики включает селектор; для DKIM селектор обязателен.
- **AC-12.2** Незавершённый обход и незавершённая проба не сохраняются в кэш как результат.
- **AC-12.3** Результат, найденный по введённому читателем селектору, не переиспользуется для запроса без селектора.
- **AC-12.4** Время наблюдения составного результата равно самому раннему из времён его частей.
