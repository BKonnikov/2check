## Разработка

Технологии: Next.js, Node.js/Fastify, PostgreSQL и Redis. Код организован как монорепозиторий pnpm:

```text
apps/
├── api/                 Веб-API и выполнение проверок
└── web/                 Пользовательский интерфейс

packages/
├── contracts/           Общие контракты данных
├── domain/              Логика проверок и оценки
└── messages/            Сообщения RU/UZ/EN
```

Для локального запуска нужны Node.js версии из `.nvmrc`, pnpm версии из `package.json` и Docker Compose. При первой настройке создайте локальную конфигурацию:

```bash
cp .env.example .env
docker compose up -d
pnpm install
pnpm build
pnpm migrate
pnpm dev
```

Веб-интерфейс доступен по адресу `http://localhost:3000`, внутренний API — на порту 3001. Redis обслуживает кэш, PostgreSQL хранит результаты сканирований. Интерфейс и сообщения поддерживают RU/UZ/EN.

Проверки приложения перед отправкой изменений:

```bash
pnpm lint
pnpm build
pnpm test
```

Для просмотра результатов модулей доступен инструмент разработчика:

```bash
pnpm inspect example.uz
pnpm inspect example.uz --address 169.254.169.254
```

## Обновление документации

Работа ведётся в **`main`**. Русская и английская версии обновляются и сверяются вместе. После редактуры выполняются сборка и проверки, описанные в [правилах работы](CONTRIBUTING.md):

```bash
python3 scripts/build_prd.py
python3 scripts/check_docs.py
```

Зафиксированный [оригинал концепции](docs/concept.md) сохранён неизменным. Обе редакции для чтения сохраняют его продуктовые решения. Два языка документации не изменяют требование продукта поддерживать RU/UZ/EN.
